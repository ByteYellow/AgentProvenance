# v0.8.2 — portable replay and Chinese support

English | [中文](https://github.com/ByteYellow/AgentProvenance/blob/v0.8.2/docs/zh-CN/releases/v0.8.2.md)

Download AgentProvenance, run `agentprov demo`, and explore what an agent did.
This release includes precompiled binaries, all demo guides, and Chinese
documentation and web interfaces.

## What's included

- **Precompiled CLI for four platforms:** Linux and macOS, each on amd64 and
  arm64. Linux archives also contain `agentprov-sensor`. Every archive includes
  demo sources, bilingual getting-started instructions and build metadata.
- **All demos in one gallery:** six signed captures and two optional evaluator
  guides. Replay verifies and imports the evidence, selects the run and view,
  and opens the dashboard. The gallery and guide reader share its visual style.
- **Chinese web interfaces:** dashboard navigation, all 12 graph views, timeline,
  details, compliance results, errors, demo guides and the Jev review workbench.
  Language switches preserve the current view and workbench drafts.
- **Chinese documentation:** installation and deployment, capture and analysis,
  demo guides, historical releases, OpenAPI, AI/MCP tools and the Python SDK.
  Chinese diagrams, screenshots and replay clips accompany the guides.
- **Language checks in CI:** document coverage, local links and heading anchors,
  UI resources, and matching English/Chinese OpenAPI contracts. The health
  response's YAML description is corrected without changing its schema.

Web pages use your saved language choice, or follow the browser on first visit.
Unsupported languages fall back to English. The CLI and tool output default to
English; `--lang zh-CN` enables the existing Chinese command-line display.
Commands, API fields, JSON values and original evidence retain their values.

## Download and try

Download an archive and its `.sha256` file from the
[v0.8.2 release](https://github.com/ByteYellow/AgentProvenance/releases/tag/v0.8.2).

| Platform | Archive |
|---|---|
| Linux / WSL, x86-64 | `agentprov_v0.8.2_linux_amd64.tar.gz` |
| Linux / WSL, ARM64 | `agentprov_v0.8.2_linux_arm64.tar.gz` |
| macOS, Intel | `agentprov_v0.8.2_darwin_amd64.tar.gz` |
| macOS, Apple Silicon | `agentprov_v0.8.2_darwin_arm64.tar.gz` |

For Linux x86-64, run these commands in the download directory:

```sh
sha256sum -c agentprov_v0.8.2_linux_amd64.tar.gz.sha256
mkdir agentprov-demo
tar -xzf agentprov_v0.8.2_linux_amd64.tar.gz -C agentprov-demo
cd agentprov-demo
./agentprov --version
./agentprov demo
```

On macOS, use the matching filename and `shasum -a 256 -c` to verify it.
Choose **Open replay** to explore evidence or **Read guide** for instructions.
Use `./agentprov demo --list` to list the examples, or
`./agentprov demo multiagent-provenance` to open one directly.
Ctrl-C stops the server and removes the temporary store.

Replay works offline without Go, a repository checkout or an API key. Running
the optional Python evaluators is a separate step described in their guides.

## Verification and platform notes

Release CI runs Go vet and race tests, checks Chinese documentation, then builds
and tests each archive on its matching Linux/macOS amd64/arm64 runner. Archive
tests remove Go from PATH and check all six signed runs, eight bilingual guides,
dashboard APIs, packaged evaluator help and normal shutdown cleanup.

Linux live capture needs a supported kernel and privileges. macOS supports
replay and application recording; Windows users run the Linux build in WSL.
Capture support is unchanged from v0.8.0. Existing stores and signed bundles
use the same formats.

`SHA256SUMS` and per-archive checksums check download integrity; `build-info.json`
identifies the source and build. macOS binaries are not Developer ID signed or
notarized. Evidence signatures use the bundled public keys and cover the saved
content.
