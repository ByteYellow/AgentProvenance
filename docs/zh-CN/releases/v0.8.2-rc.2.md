# v0.8.2-rc.2：统一示例首页与指南阅读页

[English](../../releases/v0.8.2-rc.2.md) | 中文

这个预发布版将示例体验统一到 Dashboard 的视觉风格，支持直接在浏览器中阅读指南，并包含 rc.1 引入的预编译 CLI 和全部示例回放。

## 包含内容

- 浅色示例首页，沿用 Dashboard 的颜色、字体和导航，包含六份签名采集记录及两个可选评估器示例。
- 本地指南阅读页，支持章节目录、标题、表格、内嵌图片、代码复制，以及桌面和窄屏布局。其他示例的链接仍在阅读页中打开；额外仓库链接指向本版源提交。
- 一条命令启动回放：导入前校验签名，导入后检查证据图，自动选择执行记录与视图，并在正常退出时清理临时存储。时间相关视图自动播放，部署关系视图展示拓扑。
- 更新中英文介绍、各示例入口、产品与部署指南、截图、变更记录及发行包中的 `START_HERE.md`。
- Linux/macOS 的 amd64、arm64 预编译 CLI 包。Linux 包包含 `agentprov-sensor`；所有包均附带原始示例源码。

## 下载试用

从 [rc.2 发行页](https://github.com/ByteYellow/AgentProvenance/releases/tag/v0.8.2-rc.2)下载对应平台的压缩包及 `.sha256` 文件。Linux x86-64／WSL 用户在下载目录执行：

```sh
sha256sum -c agentprov_v0.8.2-rc.2_linux_amd64.tar.gz.sha256
mkdir agentprov-demo
tar -xzf agentprov_v0.8.2-rc.2_linux_amd64.tar.gz -C agentprov-demo
cd agentprov-demo
./agentprov demo
```

Linux ARM64 使用 `linux_arm64`。macOS 按处理器选择 `darwin_amd64`（Intel）或 `darwin_arm64`（Apple Silicon），使用 `shasum -a 256 -c` 校验。

选择 **Open replay** 查看采集记录，或选择 **Read guide** 阅读说明。这些是 rc.2 的原始按钮文字。按 Ctrl-C 停止本地服务并删除临时存储。

```sh
./agentprov --version
./agentprov demo --list
./agentprov demo multiagent-provenance
./agentprov demo llm-judge
./agentprov demo k8s-cross-pod-a2a --no-browser
```

回放及内嵌指南的文字和图片可以离线使用，无需 Go、仓库检出、虚拟机、Agent 账号或 API 密钥。点击额外的仓库或外部链接时需要联网。打开 LLM Judge 和 Jev 指南不会调用服务商；运行这些 Python 示例是单独的显式操作，所需条件见各自指南。

## 验证与范围

发布检查先运行 Go vet 和竞态测试，再在 Linux/macOS 的 amd64/arm64 对应运行器上构建和运行各自的压缩包，测试时从 PATH 中移除 Go。发布前检查六份签名记录、图 API、八个指南入口、阅读页资源和正常退出清理。本地浏览器检查覆盖桌面及手机布局、章节锚点、内嵌图片、复制控件，以及 Dashboard 和示例首页的视觉一致性。

本版更新回放、界面和文档，不扩展 Linux 传感器覆盖，不改变数据库或证据格式，也不声称完成新的长期采集验收。原始签名证据包与公钥保持不变。Linux 采集仍需要支持的内核与权限；macOS 没有 Linux eBPF 传感器。强制终止可能留下临时数据。

`SHA256SUMS`、每个压缩包的校验和及 `build-info.json` 用于校验下载完整性和识别源提交。校验和不是发布者签名。macOS 二进制未经过 Apple Developer ID 签名或公证。证据包使用所附公钥校验，不能证明采集完整或所有推断成立。
