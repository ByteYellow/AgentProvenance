# v0.10.0：调查、对比与分享 Agent 执行记录

[English](../../releases/v0.10.0.md) | 中文

发布预览，待最终确认。

v0.10.0 在现有 Dashboard 中串起关联会话、正文搜索、执行对比和选择性离线分享。
新增签名示例，展示一个真实任务从诊断失败到修复成功的过程。

## 从新示例开始

在当前源码目录中运行：

```sh
go build -o agentprov ./cmd/agentprov
./agentprov demo investigation-workflow
```

命令会加载两份签名记录。在**对比**中，将 A 设为**诊断修复 · 修复前**，
将 B 设为**诊断修复 · 修复后**。沿委派关系查看代码审查，阅读已保存的测试输出，
检查访问控制决策，再比较生成的文件。示例库共提供 9 份签名回放和 11 篇示例指南。

[查看完整步骤](../../../demo/investigation-workflow/README.zh-CN.md)。

## 沿证据完成调查

- **关联会话**：查看父子会话、继续执行关系和支持这些关系的记录。
- **搜索**：检索已保存的消息、工具输入输出、配置、文件正文和运行时记录。
  结果可跳转到原文或图谱。
- **对比**：查看配置字段、文件证据、网络目标、外发数据类型和访问控制记录。
  单侧观测保留对应的采集范围说明。
- **导出回放**：选择 Run 或会话，预览包含的内容，再下载独立的只读 ZIP。
  接收方打开 `index.html` 即可阅读，无需安装 AgentProvenance。
  所选内容导出为未签名视图，来源 Bundle 保留原始签名。

图谱、风险列表和调查入口沿用现有布局。阅读长正文、搜索和对比时，再打开对应窗口。

## 阅读 AppArmor 和 seccomp 证据

支持导入或持续读取已有审计日志，并通过原生 Sensor 观察进程安全状态。
Dashboard 分别展示配置声明、实际状态、审计决策和运行时结果。
详情页根据支持证据，关联操作尝试、机制决策和实际结果。

审计采集只读已有记录。关联歧义和采集缺口与证据一起展示。
后台 API、远程 CLI、Python SDK 和 AI/MCP 工具均可查询审计关联，机器输出统一使用英文。

[访问控制指南](../security-commands.md) · [API 接入](../ai-access.md)

## 选择上下文留存范围

`launch` 和 `context import` 支持 `--capture basic|detailed`，默认使用详细档。
基础档减少补充 Agent 上下文的留存，也可用 `--capture-tool-results` 单独调整工具结果。

内核事件、TLS 正文和工作区快照独立配置。会话详情展示已保存的采集设置，
签名 Bundle 和所选回放也保留这些设置。

[采集设置说明](../agent-context.md)

## 可靠性与升级

本版完善进程生命周期与审计关联，分别记录系统调用的尝试和实际结果，
并加强 TLS/HTTP 证据处理。离线阅读保留来源引用和所选导出范围。

升级前请备份数据目录。需要回退时，将旧版程序与原数据库备份配套使用。
历史示例 Bundle 保持原样，继续提供回放。
