# v0.8.2-rc.1：预编译 CLI 与全部示例回放

[English](../../releases/v0.8.2-rc.1.md) | 中文

这个预发布版让用户无需安装 Go 或检出仓库，即可体验项目。

- 提供 Linux 和 macOS 的 amd64、arm64 预编译 CLI 压缩包。Linux 包还包含由仓库已提交绑定构建的 `agentprov-sensor`。
- 提供 `SHA256SUMS`、每个文件的 `.sha256` 和构建元数据，用于标识压缩包及其源提交。校验和用于检查下载完整性，不是发布者签名。macOS 二进制未经过 Developer ID 签名或公证。
- `agentprov demo` 打开全部既有示例的本地首页。内嵌六份签名采集记录，导入前校验签名，导入后检查证据图完整性。指定示例时自动选中执行记录和图视图；时间相关视图自动播放，部署关系视图展示拓扑。
- LLM Judge 和 Jev 提供可选接入指南。压缩包的 `demo/` 目录包含它们及其他示例的完整原始源码。实际调用评估器需要显式运行，并满足各自环境要求。
- `agentprov --version` 报告发行版本、源提交、日期和平台。

## 试用

下载对应平台的压缩包和 `.sha256` 文件。在 Linux x86-64 的下载目录执行：

```sh
sha256sum -c agentprov_v0.8.2-rc.1_linux_amd64.tar.gz.sha256
mkdir agentprov-demo
tar -xzf agentprov_v0.8.2-rc.1_linux_amd64.tar.gz -C agentprov-demo
cd agentprov-demo
./agentprov demo
```

macOS 用户按处理器选择 `darwin_amd64`（Intel）或 `darwin_arm64`（Apple Silicon），使用 `shasum -a 256 -c` 校验。Windows 用户在 WSL 中运行对应的 Linux 包。

```sh
./agentprov demo --list
./agentprov demo multiagent-provenance
./agentprov demo k8s-cross-pod-a2a --no-browser
```

回放离线、只读，在回环地址启动本地服务，使用临时存储，并在正常退出时清理。按 Ctrl-C 停止服务。强制终止可能在系统临时目录留下 `agentprov-demo-*` 目录。回放不会执行记录中的命令或 Agent。签名使用随包提供的示例公钥校验，不能据此证明采集完整或所有推断关系成立。

## 验证与限制

发布流程运行 Go vet 和竞态测试，包括六份示例的导入和篡改拒绝检查。随后，四种平台分别在对应运行器中构建、解压并运行自己的压缩包，测试时从 PATH 中移除 Go，检查首页、每份签名记录、图 API、指南和退出清理。四个平台全部通过后才能发布。这验证的是跨平台回放，不代表新增 eBPF 实机覆盖或长期节点采集验收。

Linux 运行时采集仍受内核、cgroup 和权限条件限制。macOS 支持回放和应用侧证据，没有 Linux 传感器。本版未修改采集绑定，也未改动已延后的关联和保留策略逻辑。
