# AgentProvenance v0.7.2

[English](../../releases/v0.7.2.md) | 中文

v0.7.2 加固跨环境证据采集和外发数据调查能力。该版本验证了本地进程与外部调度的 Kubernetes Pod 可以使用一致的溯源语义，核心图和存储模型不依赖具体运行环境。

## 主要变化

- 使用带过滤条件的 Kubernetes informer，在容器重启和 Pod 删除时维护 cgroup 绑定。
- 一个节点传感器观测多个工作负载。有界磁盘缓冲、背压、丢弃计数、生产者健康状态和 10 万事件实测基线，共同说明单节点能力边界。
- 用相同工作负载完成本地与 K8s 实机对照验收。两份图的校验错误和警告均为 0，规范化命令、运行时事件和进程事件语义一致。
- 外发数据视图将敏感上下文外发、源码包上传和第三方行为遥测统一为可查询证据，并关联风险和响应。
- Grok CLI 示例提供三条不同外发路径的可回放证据，分别展示各路径的行为与风险。
- 被动内核事件可以连接到按 PID 建立的进程节点，无需应用提供进程标识。

## 能力边界

生产者配置开始明确报告 `validated` 或 `planned` 状态。`local-record` 和 `k8s-daemonset` 已通过验收。`microvm-guest-init` 保留为下一步适配目标；在客体运行器和 KVM 实机验收完成前，各层可用覆盖均为空，归属置信度为 0。

中心证据服务仍是未来架构文档。本版本不包含多租户、集群调度、计费、Operator 高可用或生产级分布式控制面。

## 该版本的验证记录

- `go test ./...`
- `go vet ./...`
- Linux arm64 静态构建。
- K3s 节点多工作负载验收：8 个 cgroup、1,140 个事件，图校验错误和警告均为 0。
- K3s informer 生命周期验收：容器重启和 Pod 删除能正确关闭或重建绑定。
- 本地与 K8s 语义一致性验收：两份图的校验错误和警告均为 0。
- 10 万遥测事件压力基线：没有失败或丢弃的批次。
