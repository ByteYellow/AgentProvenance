# v0.9.0：保存、查询与回放 Agent 执行上下文

[English](../../releases/v0.9.0.md) | 中文

AgentProvenance 将一次 Agent 执行背后的上下文与运行时证据一起保存：原始任务、
对话、工具输入与结果、来源记录的权限和配置，以及文件正文。
即使原 Agent 和工作区已不在，这些记录仍可查询、导出和离线阅读。

## 核心变化

- **对话与工具结果**：共用上下文适配器，保存消息、工具结果、来源原文、
  恢复会话的历史边界及来源记录的子会话身份。
- **配置历史**：比较当时的任务、模型、工作区、审批和沙箱设置；来源提供时，
  一并保存 MCP、skills 和 plugins 信息。
- **可移植正文**：分页阅读较长工具输出，以及选择保存的变化文件最终文本；
  导出证据包并离线导入后仍可查看。
- **会话与图谱双向定位**：在双语 Dashboard 中，沿已记录的关联在工具记录与
  对应运行时证据之间切换。
- **CLI 与 HTTP 查询**：基于同一证据模型读取会话、正文、配置差异、来源覆盖和图谱关联。

## 体验 DeepSeek 回放

解压 v0.9.0 发行包后执行：

```sh
./agentprov demo deepseek-context
```

真实 Agent 为一个 Python 报表增加按日汇总，并运行七项测试。
打开 **Agent 会话**查看任务、工具输入结果与配置；使用**打开已保存内容**
阅读完整工具输出，或直接选择图中的变化文件查看最终保存的正文。

CLI 先验证原始签名，再导入独立临时存储。回放无需联网、模型凭据或 Go，
只展示已记录的执行，不会重新运行其中的命令。
示例库包含七份签名回放和九个指南入口，包括两个可选评估器示例。
[快速开始](../../../README.zh-CN.md#快速开始) · [DeepSeek 指南](../../../demo/deepseek-context/README.zh-CN.md)。

## 采集和查询你自己的 Agent

受支持的 Agent 安装并完成认证后：

```sh
./agentprov launch --file-diff -- dsh headless --json 'Inspect the project and run its tests.'
./agentprov launch --context-dir /path/to/sessions -- codex
./agentprov context coverage --run RUN_ID
./agentprov context list --run RUN_ID --kind configuration --revisions
```

| 来源 | 上下文接入方式 |
| --- | --- |
| Claude Code / Codex | 受支持的消息、工具结果及来源提供的配置 |
| DeepSeek Harness 0.1.7-rc.2 | 原生 `session.v4.jsonl.zstd` 及受支持的 v3 会话 |
| Kimi / Grok | 已有的受支持会话格式 |

上下文发现与解析在执行退出后进行，支持显式指定目录、文件或会话 ID。
恢复边界与来源身份区分历史记录和本次活动；无法唯一选定来源时，单独报告归属歧义。

[上下文指南](../agent-context.md)说明采集选项与 CLI 查询方式。
[HTTP API](../../agent-context-api.yaml)提供记录分页、正文读取、配置比较、覆盖情况和已记录的关联。

## 证据与采集

较长正文先脱敏，再计算哈希，按有界分段保存并随证据包导出。
读取已保存内容时使用证据存储，独立于当前工作区。
变化文件的最终文本由用户选择保存，表示采集时的最终状态。

上下文与运行时覆盖分别报告。来源提供的权限信息、审批策略配置与实际审批记录
保留各自含义。直接记录与关联推断分开展示，保留证据引用和置信度。
签名及图谱校验用于检查证据完整性，覆盖报告说明实际采集范围。

原生采集改进保留进程生命周期身份、内核采集时间和跨 cgroup 迁移的进程级归属。
有界关闭排空与持久化待处理批次保留迟到关联证据。
新导出包含已保存的遥测批次成员，供离线完整性校验使用。

## 升级与兼容性

- 升级前备份数据目录。已有存储升级到数据库版本 19；
  不支持用旧版二进制直接降级已升级的数据库。
- 六份历史签名 demo 的证据包、签名和公钥不变；历史记录未提供的新上下文字段保持为空。
- Linux amd64/arm64 内核采集需要相应内核、cgroup 和 BPF/perf 权限。
  macOS 提供回放与应用侧记录。逐项探针和 TLS 支持范围见[部署指南](../amd64-kvm-k3s.md)。
- `launch` 签名仍通过 `--sign-key` 显式启用；`--file-diff` 用于工作区比较和保存变化文件最终文本。
- LLM/Jev 评估器保持可选示例，独立于采集主路径。

详细变化见[变更记录](../../../CHANGELOG.zh-CN.md)。
