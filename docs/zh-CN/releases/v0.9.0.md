# v0.9.0 — 从任务到结果，看清 Agent 的一次执行

[English](../../releases/v0.9.0.md) | 中文

v0.9.0 在执行页面中加入 **Agent 会话**。现在可以查看任务、对话、工具输入和结果，
了解当时的权限与运行配置，再从工具调用追到进程和文件证据。
这些记录会随执行证据一起导出，换一台机器也能继续查看。

本版本已完成验收，等待发布前审阅。

## 一条命令体验

解压 v0.9.0 发行包后执行：

```sh
./agentprov demo deepseek-context
```

这是一份真实的 DeepSeek Harness 开发记录：给 Python 报表增加按日汇总，并通过七项测试。
回放可离线使用，无需 Go、模型账号或 API Key。示例库现有七份签名回放和九篇指南。

正式包发布前，可按[快速开始](../../../README.zh-CN.md#快速开始)从源码构建。

## 这次新增了什么

### 在图谱下面，直接查看对话和工具结果

执行图谱仍在上方，**Agent 会话位于下方，默认收起**。
展开后可以查看用户和助手消息、工具输入、结果与错误，
并沿已记录的关联在工具调用与运行时证据之间跳转。
原有时间线、进程树、网络和风险视图继续保留。

### 留下当时的任务、权限和配置

保存 Agent 日志中的任务、模型、工作目录、审批策略和沙箱设置；
日志提供 MCP、skills 或 plugins 信息时，也一并保留。
选中两份任务、配置或审批记录，就能比较同一执行内或两次执行之间的变化。

配置和实际审批决定分开展示。日志里没有审批决定时，界面显示“未记录”。

### 工具输出和文件正文，离线也能完整阅读

较长的工具结果和原始记录在独立阅读区分页显示。
启用 `--file-diff` 后，还会保存变更文件的最终文本。
在图中选择文件即可打开正文，收起 Agent 会话后也能继续阅读。
签名导出、离线导入后，这些内容仍然可用。

### 看清采到了什么、缺了什么

**采集情况**列出读取的会话来源、缺失字段和解析错误，同时展示运行时探针覆盖及关联缺口。
无法确定的数量保留为未知。CLI、HTTP API 和证据包提供相同报告，
换一台机器回放时，仍能看到原来那次采集的情况。

### 接入 DeepSeek Harness，完善已有适配器

| Agent | 支持的会话内容 |
| --- | --- |
| Claude Code | Hooks、原生消息与工具、权限模式变化和会话状态 |
| Codex | 原生 rollout 消息与工具、续跑线程、配置及日志提供的子会话身份 |
| DeepSeek Harness | v3 JSONL 和原生 v4 Zstandard 会话、工具及配置 |
| Kimi / Grok | 已有适配器支持的会话格式 |

Claude Code 2.1.293 和 Codex 0.159.2 已通过真实任务与续跑验证。
DeepSeek 签名开发示例使用 Harness 0.1.7-rc.2。
具体格式见[兼容性表](../agent-context.md#原生格式兼容性)。
会话在 Agent 退出后整理，支持自定义目录、指定会话、恢复历史以及重复导入去重。

## 记录你自己的会话

安装并登录对应 Agent 后：

```sh
./agentprov launch --file-diff -- claude
./agentprov launch --context-dir /path/to/sessions -- codex
./agentprov launch --file-diff -- dsh headless --json 'Inspect the project and run its tests.'
./agentprov context coverage --run RUN_ID
./agentprov context list --run RUN_ID --kind configuration --revisions
```

## 可靠性与兼容性

本次还完善了进程身份、cgroup 迁移、迟到事件补关联和持久化采集。
amd64 预编译探针已补齐子进程创建时的 cgroup 修复，真实进程生命周期检查也已加入 CI。

验收包含 **485 项浏览器检查**、六份历史签名包、数据库 17→19 升级，
以及 x86 KVM/K3s 与 TLS 实测。远端 CI 和 Linux/macOS 的 amd64、arm64 便携包均已通过。
具体结果和复验步骤见[验收报告](../../benchmarks/v0.9.0-acceptance/README.zh-CN.md)。
24 小时长稳测试按此前安排暂缓，本轮未重复 ARM 实机验收。

## 升级前需要知道

- 先备份数据目录。v0.9.0 会将数据库升级到版本 19，升级后不支持直接用旧版程序打开。
- 六份历史签名示例保留原始签名和内容；过去没有记录的会话字段仍显示为未记录。
- Linux 原生采集需要相应内核和权限；macOS 支持应用侧记录与回放。
  详见[平台与 TLS 指南](../amd64-kvm-k3s.md)。
- `--sign-key` 用于启用签名，`--file-diff` 用于保存变更文件的最终正文，两项均按需开启。
