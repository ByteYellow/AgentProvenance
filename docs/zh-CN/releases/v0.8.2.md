# v0.8.2：下载即用的回放体验与中文支持

[English](https://github.com/ByteYellow/AgentProvenance/blob/v0.8.2/docs/releases/v0.8.2.md) | 中文

下载 AgentProvenance，运行 `agentprov demo`，即可查看 Agent 的执行过程。本版提供预编译程序、全部示例指南，以及中文文档和网页界面。

## 本版内容

- **四个平台的预编译 CLI**：Linux 和 macOS，均支持 amd64、arm64。Linux 包还包含 `agentprov-sensor`。每个包附带示例源码、中英文入门指南和构建信息。
- **统一的示例首页**：集中展示六份签名采集记录和两个可选评估器指南。打开回放时自动校验、导入证据并选择执行记录和视图。首页、阅读页与 Dashboard 使用同一套样式。
- **中文网页界面**：覆盖 Dashboard 导航、12 种图视图、时间线、详情、合规结果、错误提示、示例指南和 Jev 复核工作台。切换语言后保留当前视图与未保存的复核草稿。
- **中文文档**：覆盖安装部署、采集分析、示例、历史版本、OpenAPI、AI/MCP 工具和 Python SDK，并配有中文图示、截图和回放动画。
- **持续检查**：CI 检查中文文档是否缺页、链接和章节跳转是否有效，以及界面词条和双语 OpenAPI 是否一致。同时修正健康接口说明的 YAML 格式，接口字段不变。

网页优先使用已保存的语言选择；首次访问时跟随浏览器语言，无法匹配时使用英文。命令行和工具输出默认英文，已有的 `--lang zh-CN` 中文显示选项继续可用。命令、API 字段、JSON 值和原始证据保持原样。

## 下载并体验

从 [v0.8.2 发行页](https://github.com/ByteYellow/AgentProvenance/releases/tag/v0.8.2)下载对应平台的压缩包和同名 `.sha256` 文件。

| 平台 | 压缩包 |
|---|---|
| Linux / WSL，x86-64 | `agentprov_v0.8.2_linux_amd64.tar.gz` |
| Linux / WSL，ARM64 | `agentprov_v0.8.2_linux_arm64.tar.gz` |
| macOS，Intel | `agentprov_v0.8.2_darwin_amd64.tar.gz` |
| macOS，Apple Silicon | `agentprov_v0.8.2_darwin_arm64.tar.gz` |

以 Linux x86-64 为例，在下载目录执行：

```sh
sha256sum -c agentprov_v0.8.2_linux_amd64.tar.gz.sha256
mkdir agentprov-demo
tar -xzf agentprov_v0.8.2_linux_amd64.tar.gz -C agentprov-demo
cd agentprov-demo
./agentprov --version
./agentprov demo
```

macOS 使用对应文件名，并用 `shasum -a 256 -c` 校验。

点击**打开回放**查看证据，点击**阅读指南**查看操作说明。`./agentprov demo --list` 列出全部示例，`./agentprov demo multiagent-provenance` 可直接打开指定示例。按 Ctrl-C 停止服务并清理临时数据。

回放支持离线使用，无需安装 Go、下载源码或配置 API Key。可选的 Python 评估器需要按各自指南单独运行。

## 验证与平台说明

发布流程执行 Go 静态检查、竞态测试和中文文档检查，再在对应的 Linux/macOS amd64/arm64 环境中构建并验收压缩包。验收时从 PATH 中移除 Go，检查六份签名记录、八个双语指南、Dashboard 接口、包内评估器帮助，以及正常退出后的清理。

Linux 实时采集需要相应内核和权限；macOS 支持回放及应用侧记录；Windows 用户在 WSL 中运行 Linux 包。采集能力沿用 v0.8.0，已有数据目录和签名证据包的格式不变。

`SHA256SUMS` 和单独的校验文件用于检查下载完整性，`build-info.json` 记录源提交和构建信息。macOS 二进制尚未经过 Developer ID 签名或公证。示例证据使用随包公钥验证签名，签名覆盖保存的内容。
