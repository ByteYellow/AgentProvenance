# 安全政策

[English](../../SECURITY.md)

## 支持的版本

安全修复面向最新正式发布版本。使用旧版本的用户应升级；如果同时为其他版本
提供修复，会在对应安全公告中说明。

## 报告安全漏洞

请通过 [GitHub 私密漏洞报告](https://github.com/ByteYellow/AgentProvenance/security/advisories/new)
提交。也可以在仓库的 **Security → Advisories → Report a vulnerability** 中打开
报告表单。报告通过私密渠道处理，不会作为公开 Issue 展示。

也可以发送邮件至 [byteyellow@qq.com](mailto:byteyellow@qq.com)，主题使用
“[AgentProvenance Security] 问题简述”。协调披露期间，请将漏洞细节和利用代码
保留在私密沟通中。

建议提供受影响的版本或提交、操作系统与部署方式、所需访问权限、预期影响，
以及复现步骤或最小概念验证。附件请使用合成凭据，并删除无关敏感信息。
尚未准备好完整复现时，也欢迎先提交已有线索。

## 报告范围

欢迎报告影响 AgentProvenance 自身安全性的问题，包括未授权访问、凭据泄露、
导入 Bundle 或处理 Agent 可控内容时的不安全行为、签名验证绕过、证据完整性
受损，以及可利用的资源耗尽。

请说明攻击者如何触达相关组件，以及造成的具体影响。不确定问题是否涉及
安全时，可以先私密联系。

## 响应与处理

我们的目标是在七个工作日内首次响应。初步评估后，会沟通影响范围、缓解措施
和后续处理安排。

修复优先级依据可利用性和影响确定。处理周期取决于具体问题，上述时间属于
维护目标，而非保证履行的服务等级协议。

## 协调披露

我们会与报告者协调公开时间。安全公告将说明受影响版本、修复版本，以及
缓解措施或升级指引。

经报告者同意后，我们会公开致谢。请仅在自己拥有或获得授权的系统与数据上
开展测试。

## 其他问题

普通缺陷、使用问题和功能建议，请通过
[GitHub Issues](https://github.com/ByteYellow/AgentProvenance/issues) 提交。
