# 中文适配与验收

v0.8.2 提供中文文档、Dashboard、示例页面和评估器工作台。使用入口见[发行说明](releases/v0.8.2.md)。

## 语言规则

- 网页依次使用 URL 中的语言、已保存的选择、浏览器偏好；无法匹配时使用英文。
- 手动切换后保留选择，页面跳转沿用该语言。Dashboard 当前视图和工作台未保存的草稿也会保留。
- CLI、传感器、后台服务及脚本默认输出英文。已有的 `--lang zh-CN` 选项继续可用，工具诊断不要求逐条翻译。
- 命令、参数、API 字段、ID、路径、JSON 值和原始证据保留原样。界面为这些内容提供中文标签。

## 写作与展示

参考[中文技术文档写作规范](https://github.com/ruanyf/document-style-guide)，使用常用词、短句和自然的中文语序。标题直接说明内容，功能介绍直接讲用途、操作和结果。

中文使用全角标点，与英文、数字之间留空格。同一概念保持一致，例如“执行记录”“运行环境”“事件归属”“污点传播”和“图视图”。

页面标签保持简短。合规状态使用“阻断、仅检测、未触发、尚无规则”，命中次数显示为“命中 ×N”，展开后查看每次决策。环境要求和能力限制集中放在对应指南，避免每段重复。

## 可复现检查

中文文档检查只需要 Python 3.9+：

```sh
python3 scripts/check_localized_docs.py
```

它检查每份已跟踪的英文 Markdown 使用文档是否有中文版本，以及中文文档中的本地链接、图片和章节锚点。CI 和正式发布流程都会执行它。

Dashboard 浏览器检查需要 Playwright。先运行 `agentprov demo --no-browser`，再将输出地址传给脚本：

```sh
node scripts/accept_dashboard_i18n.cjs http://127.0.0.1:PORT
```

将 `PORT` 替换为实际端口。可设置 `PLAYWRIGHT_CHANNEL=msedge` 使用本机 Edge，否则使用 Playwright 的 Chromium。

`scripts/accept_jev_i18n.cjs` 检查工作台语言与交互，仅使用新的合成测试数据，避免修改真实评审。真实请求响应、模型回答和原始签名包不参与翻译。

## 发布门禁

[发布工作流](../../.github/workflows/release.yml)先运行中文文档检查、Go 静态检查和竞态测试，再分别构建四个平台的压缩包。

每个平台执行 `scripts/accept_release.py`：校验下载哈希和版本信息，在 PATH 不包含 Go 的环境中打开六份签名记录、八个双语指南，检查 Dashboard 接口、评估器帮助与退出清理。工作流收集四份通过验收的压缩包，生成 `SHA256SUMS` 后发布。

[x86 采集与基础 CI](../../.github/workflows/ci.yml)继续检查 Linux 双架构构建、eBPF 绑定及 Go 1.23–1.26 的 amd64 系统调用和 TLS 采集。本次中文适配沿用已有采集能力与证据格式。
