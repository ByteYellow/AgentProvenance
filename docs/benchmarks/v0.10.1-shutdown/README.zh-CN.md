## 修复内容

停止采集时，先卸载系统调用探针，停止 TLS 发现并卸载其探针，再排空缓冲。
此时待处理记录的集合已经固定，节点上的其他工作负载可以继续运行。
卸载或排空失败会返回错误，清理过程也会等待停机协程结束。

当前 ELF 错误文案已补齐中文翻译和持久化诊断格式。历史记录使用的旧文案继续保留。
协议错误仍使用英文，中文转换只发生在展示时。

## 复现方法

在具备 eBPF 权限、C 编译器和 OpenSSL 开发头文件的 Linux 测试节点执行：

```sh
go test -c -race -o /tmp/sensor.test ./internal/sensor
cd internal/sensor
sudo env AGENTPROV_LIVE_SHUTDOWN=1 /tmp/sensor.test \
  -test.run '^TestLiveSensorShutdown$' -test.count=3 -test.v -test.timeout=90s
```

用例让四个线程持续打开文件，直到采集器退出后才结束负载。
原有[压力验收](../../../scripts/accept_sensor_pressure.py)检查另一种情况：先结束工作负载，
再确认停止采集时保留全部待处理的操作尝试、结果和进程退出记录。
Linux CI 的原生采集任务已加入持续负载下的停机回归。

此前后续验收中的翻译日志早于最终源码一致性检查发现的失败。
旧日志保留作为历史记录，翻译结论以本报告为准。
