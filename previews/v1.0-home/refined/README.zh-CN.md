# 首页精修预览

[English](README.md) | 中文

这是[现有首页预览](../README.zh-CN.md)的独立视觉版本，保留项目标识、四个精选案例、三个专题、案例档案和阅读器入口。调整集中在排版、间距和证据图片，记录数据保持原样。同一套资源已用于正式站点构建，本独立版本继续保留对比入口。

## 构建与查看

先构建并启动原有首页预览，再将本版本加入同一个目录。原来的 `index.html` 会保留。

```sh
python3 previews/v1.0-home/refined/build.py --site output/home-review
node previews/v1.0-home/refined/check.cjs http://127.0.0.1:58729/
```

新版本入口为 `/refined.html?lang=zh-CN`，上一版入口为 `/?lang=zh-CN`。页面提供返回上一版的链接，两版共用阅读器、文档和下载内容。

检查范围包括中英文、四档屏幕宽度、档案导航、文档图标、关闭后的焦点恢复、语言切换和修复对比直达。

本轮修复对比将检查任务 `run-860466af8a9a` 放在 A 侧，修复任务 `run-3bfc6838a9c6` 放在 B 侧。历史案例仍使用各自的对比组合。

## 图片来源

图片来自已保存的公开记录，包括文件对比、工作区产物表、浏览器截图和协作图。`media/sources.json` 保存入口、证据引用和图片哈希。

工作区图片选取现有阅读器中的文件变更表；浏览器和图谱图片展示局部细节。所有值和关系都来自原始记录。

重新截图：

```sh
node previews/v1.0-home/refined/capture.cjs http://127.0.0.1:58729/
```
