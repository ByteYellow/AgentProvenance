# 开发任务

以下是采集时实际提交的[英文任务](TASK.md)的中文说明。

为 `report.py` 实现 `--daily`：按日期升序输出每天已支付订单的收入。
不使用该选项时，保持现有输出不变。使用 Decimal，排除已取消订单，
增加并运行测试，最后简要说明修改与测试结果。

预期每日收入为：2026-09-25：30.00；2026-09-26：7.25；2026-09-27：4.75。
现有总额保持 42.00。

工作区为一次性目录，订单均为虚构数据。只修改该目录中的文件，只使用 Python
标准库，不安装依赖、不通过工具发送网络请求，也不读取工作区外的配置或凭证。
运行测试可以生成普通临时文件。需要额外权限时先询问，不编造测试结果。
